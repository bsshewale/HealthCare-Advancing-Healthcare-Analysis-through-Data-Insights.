# Hospital Performance Dashboard
## Overview

This Power BI project analyzes hospital performance using 1,000 patient records, covering demographics, treatments, diagnoses, costs, and outcomes. The dashboard provides actionable insights into patient trends, hospital efficiency, treatment effectiveness, and financial performance.

## Key Insights
### Patient Demographics

Seniors are the largest patient group, mainly with hypertension, diabetes, and COVID-19.

Gender distribution is balanced across age groups.

### Hospital Performance Comparison

Riverside Hospital: best cost-to-recovery ratio.

Green Valley Medical Center: higher costs, lower recovery outcomes.

### Treatment Effectiveness

Therapy: superior recovery at lowest cost.

Medication: highest expense with suboptimal recovery.

Surgery: balanced cost-effectiveness.

### Diagnosis Analysis

Chronic conditions: steady costs, moderate recovery.

COVID-19: high costs, improving recovery (2021–2023).

Acute conditions: optimal cost-to-recovery balance.

### Temporal Trends

Admissions peak during March–May, dip in Nov–Dec.

Costs stabilized between 2021–2023.

### Performance Overview

Total Revenue: ₹9.44M (from 1,000 patients)

Average Bill: ₹9,437 per patient

Recovery Rating: 5.38/10 (moderate)

Average Stay: 1 day (short-term care)
